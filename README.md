# THe-Process-ScehDuler-
# ⚙️ Process Scheduling Simulator

A simple **Operating System** project that simulates different CPU scheduling algorithms:
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Round Robin

---

## 🧠 Features
- Calculates **Waiting Time** and **Turnaround Time**
- Displays scheduling results in a clean table format
- Simulates time-sharing for Round Robin
- Menu-driven interface

---

## 🧰 Tech Stack
- Language: **C**
- Compiler: `gcc` or any C IDE (Code::Blocks, VS Code, Turbo C)

---

## ▶️ How to Run
```bash
gcc process_scheduler.c -o scheduler
./scheduler
